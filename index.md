# Политика конфиденциальности приложения TapMaster

Дата вступления в силу: 18.09.26

## Кратко

TapMaster не собирает и не хранит на серверах разработчика никаких персональных данных.
Счётчики нажатий и настройки хранятся только на вашем устройстве, в зашифрованном виде.
Приложение показывает рекламу через сеть Яндекс Рекламы (Yandex Mobile Ads SDK), которая
для показа рекламы обрабатывает часть технических данных устройства — подробности ниже.

## Какие данные хранятся на устройстве

Приложение сохраняет локально, на вашем устройстве:

- названия и настройки созданных вами счётчиков (проектов);
- историю сессий (количество нажатий, длительность, скорость);
- пользовательские настройки (тема оформления, звук, вибрация).

Название счётчика и настройки приложения хранятся в **зашифрованном виде** (AES-256-GCM) с
использованием ключа, который создаётся на вашем устройстве и хранится в защищённом системном
хранилище Android Keystore. Этот ключ не покидает устройство и не передаётся разработчику.
Разработчик не имеет доступа к этим данным.

## Реклама и сеть Яндекс Рекламы

Приложение использует Yandex Mobile Ads SDK (Яндекс Реклама) для показа баннерной рекламы
и рекламы с вознаграждением. Для этого приложению требуется доступ к интернету.

При показе рекламы Yandex Mobile Ads SDK может обрабатывать следующие технические данные
вашего устройства: рекламный идентификатор (Advertising ID), общие параметры устройства
(модель, версия ОС, язык, часовой пояс), IP-адрес и данные о взаимодействии с рекламой
(показы, клики). Эти данные обрабатываются Яндексом в соответствии с его собственной
политикой конфиденциальности, доступной по адресу:
https://yandex.ru/legal/confidential/

Вы можете ограничить использование рекламного идентификатора для персонализации рекламы в
настройках вашего устройства Android (Настройки → Google → Реклама → Удалить рекламный ID
или Отключить персонализацию рекламы).

## Куда передаются данные

Данные о счётчиках, названиях проектов и настройках **никогда** не передаются никуда — они
существуют только локально на вашем устройстве и не отправляются ни разработчику, ни
третьим лицам. Единственный сетевой трафик приложения — это запросы рекламных блоков к
Yandex Mobile Ads SDK, описанные в разделе выше.

## Экспорт данных

Приложение позволяет вам самостоятельно экспортировать статистику по счётчику в файл CSV
или JSON через стандартное меню «Поделиться» операционной системы Android. Экспорт
происходит только по вашему явному действию, и вы сами выбираете, куда отправить файл.

## Разрешения приложения

- **Вибрация** (`VIBRATE`) — для тактильной отдачи при нажатии. Не даёт доступа к личным
  данным и не требует подтверждения пользователем.
- **Интернет** (`INTERNET`, `ACCESS_NETWORK_STATE`) — необходимы для показа рекламы через
  Yandex Mobile Ads SDK.

## Удаление данных

Все локальные данные приложения (счётчики, статистика, настройки) удаляются автоматически
и безвозвратно при удалении приложения с устройства, либо вручную через
Настройки Android → Приложения → TapMaster → Хранилище → Очистить данные.

## Дети и возрастные ограничения

Приложение не собирает персональные данные от пользователей на своей стороне. Если ваше
приложение ориентировано на детскую аудиторию, обратите внимание, что показ рекламы детям
регулируется отдельными правилами платформ (например, Google Play Families Policy) — при
необходимости включите режим ограничения персонализации рекламы для детей через
соответствующий флаг Yandex Mobile Ads SDK (см. документацию SDK, раздел COPPA).

## Изменения политики

При изменении функциональности приложения эта политика будет обновлена, актуальная версия
будет доступна по той же ссылке.
